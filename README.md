# SmartBlinks UI Preview

A public, independent front-end prototype for reviewing SmartBlinks' proposed mobile-first trading-terminal experience.

## What this is
- Standalone HTML, CSS, and JavaScript. No build step required.
- Simulated account balance, equity, P&L, market prices, chart updates, demo connection state, and local test positions.
- Navigation, risk summary, event stream, responsive layout, and optional subtle interface sounds.
- No backend, broker API, cTrader connection, or real order execution.

## Deploy on Render
Create a **Static Site** from this repository:
- Branch: `main`
- Build command: leave empty
- Publish directory: `.`

The site is designed to be opened directly on desktop or mobile. All trading figures and positions are illustrative and stay in the current browser session.

## Important
This is a UI prototype, not trading software. It must never be used to infer live account state, trading performance, or actual risk controls.
